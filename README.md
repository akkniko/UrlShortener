# URL Shortener

Небольшой сервис сокращения ссылок на Java. Приложение принимает длинный URL, создаёт короткий код, перенаправляет пользователя по этому коду и собирает статистику переходов.

## Возможности

- Создание коротких ссылок для HTTP и HTTPS URL.
- Генерация случайного кода или задание собственного алиаса.
- Проверка уникальности алиаса и повторная генерация кода при коллизии.
- Срок действия ссылки (по умолчанию 24 часа).
- HTTP 302 redirect и запись каждого перехода в PostgreSQL.
- Общее количество переходов и статистика по календарным дням (дни без переходов также показываются с нулём).
- Простая HTML-страница для создания ссылок и просмотра статистики.
- Unit-тесты бизнес-логики без подключения к базе данных.

## Стек

- Java 21
- Maven
- Jakarta Servlet API и embedded Apache Tomcat 10.1
- PostgreSQL 17, JDBC, HikariCP
- Jackson (`JavaTimeModule`)
- JUnit 5 и Mockito
- Docker Compose

## Требования

- JDK 21 или новее (для сборки используется `--release 21`).
- Docker Engine и Docker Compose v2.
- Для запуска через Maven Wrapper интернет нужен при первой загрузке Maven и зависимостей.

## Запуск

### Linux / macOS

```bash
cp .env.example .env
./run.sh
```

### Windows PowerShell

```powershell
Copy-Item .env.example .env
.\run.ps1
```

Скрипт поднимает PostgreSQL, собирает исполняемый JAR и запускает приложение. После запуска откройте:

- Веб-страница: http://localhost:8080/
- API: http://localhost:8080/api/links

Остановка приложения — `Ctrl+C`. Остановка базы данных:

```bash
docker compose down
```

Данные PostgreSQL сохраняются в Docker volume `pgdata`. Чтобы удалить базу вместе с данными:

```bash
docker compose down -v
```

### Ручной запуск

1. Запустите PostgreSQL:

   ```bash
   docker compose up -d --wait
   ```

2. Настройте переменные окружения (при необходимости) и соберите проект:

   ```bash
   ./mvnw clean package
   ```

3. Запустите приложение:

   ```bash
   java -jar target/url-shortener.jar
   ```

При старте приложение создаёт таблицы `links` и `clicks`, если они ещё не существуют.

## Конфигурация

Параметры задаются переменными окружения. Значения по умолчанию предназначены только для локальной разработки.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DB_URL` | `jdbc:postgresql://localhost:5432/urlshortener` | JDBC URL базы данных |
| `DB_USER` | `app` | Пользователь PostgreSQL |
| `DB_PASSWORD` | `dev_password` | Пароль PostgreSQL |
| `DB_POOL_SIZE` | `10` | Максимальный размер пула соединений |
| `PORT` | `8080` | HTTP-порт приложения |
| `LINK_TTL_HOURS` | `24` | Время жизни новой ссылки в часах |

Файл `.env` предназначен для локальных настроек и исключён из Git. Если меняете значения в `.env`, скрипты запуска передают их и приложению.

## API

Все тела запросов и ответов используют JSON в UTF-8. Временные метки возвращаются в ISO-8601.

| Метод | Endpoint | Назначение | Успешный ответ |
|---|---|---|---|
| `POST` | `/api/links` | Создать короткую ссылку | `201 Created` |
| `GET` | `/r/{code}` | Перейти по короткой ссылке | `302 Found` |
| `GET` | `/api/links/{code}` | Получить сведения и статистику | `200 OK` |

### Создание ссылки

```bash
curl -i -X POST http://localhost:8080/api/links \
  -H 'Content-Type: application/json' \
  -d '{"originalUrl":"https://example.com/articles/java","alias":"java-notes"}'
```

Поле `alias` необязательно. Если оно не передано или равно `null`, сервис сгенерирует случайный код. Допустимы латинские буквы, цифры, `_` и `-`; длина собственного алиаса — от 1 до 32 символов.

Пример ответа `201 Created`:

```json
{
  "code": "java-notes",
  "originalUrl": "https://example.com/articles/java",
  "createdAt": "2026-11-08T09:00:00Z",
  "expireAt": "2026-11-09T09:00:00Z"
}
```

### Переход

```bash
curl -i http://localhost:8080/r/java-notes
```

При активной ссылке сервер возвращает `302 Found` и заголовок `Location` с исходным URL. Переход сохраняется в таблице `clicks`.

### Статистика

```bash
curl http://localhost:8080/api/links/java-notes
```

Пример ответа:

```json
{
  "link": {
    "code": "java-notes",
    "originalUrl": "https://example.com/articles/java",
    "createdAt": "2026-11-08T09:00:00Z",
    "expireAt": "2026-11-09T09:00:00Z"
  },
  "totalClicks": 2,
  "dailyStats": [
    {"day": "2026-11-08", "clicks": 2}
  ]
}
```

Даты статистики группируются по UTC. Между датой создания ссылки и датой окончания её срока действия включительно сервис возвращает каждый календарный день; если переходов не было, `clicks` равен `0`.

## HTTP-ошибки

| Статус | Причина |
|---|---|
| `400 Bad Request` | Неверный JSON, URL или алиас |
| `404 Not Found` | Код ссылки не существует |
| `409 Conflict` | Собственный алиас уже занят |
| `410 Gone` | Срок действия ссылки истёк |
| `500 Internal Server Error` | Непредвиденная ошибка сервера или базы данных |

Ошибки возвращаются в JSON, например:

```json
{
  "status": 409,
  "error": "Alias 'java-notes' is already taken",
  "path": "/api/links",
  "timestamp": "2026-11-08T09:00:00Z"
}
```

## Тесты

Тесты не требуют запущенного PostgreSQL:

```bash
./mvnw test
```

Проверяются генератор кода и бизнес-логика: корректный и некорректный URL, занятый алиас, коллизия случайного кода, успешный переход, истёкшая и несуществующая ссылка.

```text
src/main/java/com/example/demo/
├── config/          # Настройка DataSource и инициализация схемы

├── repository/      # Контракты репозиториев
│   └── jdbc/        # JDBC-реализации
├── servlets/        # HTTP endpoints и главная страница
├── service/         # Бизнес-логика и статистика
└── Main.java        # Сборка зависимостей и запуск embedded Tomcat
```

## Ограничения

Проект предназначен для учебных целей и демонстрации Java backend: Servlet API, JDBC, PostgreSQL, DI через конструкторы, обработка ошибок и тестирование. В нём пока нет аутентификации, rate limiting, защиты от массового создания ссылок и механизма фонового удаления истёкших записей. Значения доступа к БД по умолчанию небезопасны и не должны использоваться в production.
